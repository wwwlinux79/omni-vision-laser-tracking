┌─────────────────────────────────────────────────────────────────┐

│    ./tune_laser_aim.py --show                                   │

│  调整超调:                                                       │

┌─────────────────────────────────────────────────────────────────┐
│ 🛠️ 故障排除                                                      │
├─────────────────────────────────────────────────────────────────┤
│  找不到Pico:                                                     │
│    ls /dev/ttyACM*                                              │
│    sudo usermod -a -G dialout $USER   # 然后重新登录            │
│                                                                  │
│  pigpiod未运行:                                                  │
│    sudo pigpiod                                                 │
│    sudo systemctl enable pigpiod                                │
│                                                                  │
│  摄像头无响应:                                                   │
│    vcgencmd get_camera                                          │
│    libcamera-hello --timeout 2000                               │
│                                                                  │
│  找不到标记:                                                     │
│    cd /home/pi4/project/基本功能                                 │
│    python control.py observe --marker-id 0                      │
│                                                                  │
│  找不到激光光点:                                                 │
│    - 检查激光是否开启（GPIO17）                                  │
│    - 确保激光在摄像头视野内                                      │
│    - 检查环境光照（不能太亮）                                    │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ 📊 默认参数                                                      │
├─────────────────────────────────────────────────────────────────┤
│  YAW_THRESHOLD      = 20 像素   (水平误差阈值)                   │
│  PITCH_THRESHOLD    = 12 像素   (垂直误差阈值)                   │
│  PITCH_GAIN         = 0.15      (俯仰调整增益)                   │
│  MAX_PITCH_STEP     = 15 µs     (最大俯仰步长)                   │
│  YAW_DURATION_MS    = 100 ms    (底盘旋转时长)                   │
│  FRAME_DELAY        = 0.08 s    (帧间延迟)                       │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ 💡 提示                                                          │
├─────────────────────────────────────────────────────────────────┤
│  • 首次使用先运行 ./check_system.sh 检查系统状态                 │
│  • 确保ArUco标记清晰可见且在摄像头视野内                          │
│  • 激光和标记都要在摄像头视野内                                   │
│  • 环境光不能太强，否则影响激光光点检测                           │
│  • 调参后需重启系统才能生效                                       │
│  • 按Ctrl+C安全停止系统（激光会自动关闭）                         │
