# 动态追踪系统

## 当前启动方式

运行 `./start_laser_aim.sh`。小车按基本功能的前进参数连续行驶 1.5 秒，停车后使用静态追踪的相机输出 ArUco 标记坐标。

启动脚本接受 `--marker-id`、`--port`、`--speed` 和 `--min-duty`。下方保留旧版本的说明。

## 🎯 用途

**底盘持续前进，同时进行视觉追踪**

- 底盘以恒定速度前进
- 云台实时调整俯仰角度
- 底盘根据目标位置微调方向
- 保持激光始终瞄准移动目标

## 📊 控制参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 前进速度 | 0.3 | 底盘持续前进速度 |
| 水平阈值 | 20 像素 | 超过此误差才微调方向 |
| 垂直阈值 | 8 像素 | 超过此误差才调整俯仰 |
| 方向微调速度 | 0.15 | 边走边转的速度 |
| 俯仰增益 | 0.12 | 控制俯仰响应速度 |
| 最大俯仰步长 | 8 微秒 | 单次最大俯仰调整量 |
| 帧延迟 | 0.15 秒 | 两次调整间隔 |

## 💡 工作原理

```
1. 底盘持续前进 → 以恒定速度0.3前进
2. 检测标记位置 → 实时识别画面中的ArUco标记
3. 计算误差 → 
   - 水平误差 = 标记x - 画面中心x (320)
   - 垂直误差 = 标记y - 画面中心y (240)
4. 方向微调 →
   - 标记在左侧 → 边走边向左转
   - 标记在右侧 → 边走边向右转
5. 垂直控制 →
   - 标记在上方 → 云台向上转
   - 标记在下方 → 云台向下转
6. 持续追踪 → 保持激光瞄准移动目标
```

## 🔧 参数调整

### 如果前进速度太快
编辑 `laser_aiming.py`，修改：
```python
FORWARD_SPEED = 0.2  # 降低速度
```

### 如果方向调整不够灵敏
```python
YAW_THRESHOLD = 15      # 降低阈值
YAW_SPEED_ADJUST = 0.20  # 提高微调速度
```

### 如果追踪不够稳定
```python
FRAME_DELAY = 0.20  # 增加延迟，提高稳定性
```

## ⚠️ 安全注意事项

1. **确保前方空间**
   - 底盘会持续前进
   - 至少需要3-5米的直线空间
   - 避免障碍物和台阶

2. **准备紧急停止**
   - 按 `Ctrl+C` 立即停止
   - 或准备手动断电

3. **测试环境**
   - 在开阔空间测试
   - 避免人员密集区域
   - 确保地面平整

## 🆚 与静态追踪的区别

| 特性 | 静态追踪 | 动态追踪 |
|------|---------|---------|
| 底盘移动 | ❌ 原地不动/旋转 | ✅ 持续前进 |
| 适用场景 | 固定目标 | 移动目标 |
| 空间需求 | 小 | 大（需要前进空间） |
| 追踪方式 | 云台+底盘旋转 | 云台+方向微调 |
| 对准精度 | 高（可完全静止） | 中（持续移动） |
